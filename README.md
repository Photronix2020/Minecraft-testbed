# Tower Defense (Minecraft Forge 1.20.1)

A self-contained tower defense game for Minecraft Java **1.20.1 / Forge 47+**. Join a world and play, with no setup commands.

## How to play
1. Place the **Defense Core** on open, flat ground and **right-click** it. (New players automatically get one, plus 20 coins and a crafting table. `/tdkit` gives the kit again.)
2. You get 30 seconds of prep time, then **12 waves** of glowing monsters spawn in a ring ~22 blocks out and walk to the Core. Boss waves are 6 and 12.
3. Craft towers at a crafting table (shapeless, coins only):

| Tower | Cost | Does |
|---|---|---|
| Arrow Tower | 3 coins | fast, single target |
| Frost Tower | 5 coins | weak damage, slows enemies in an area |
| Cannon Tower | 7 coins | slow, big area damage |

4. Place towers along the enemy path. Killing monsters drops coins; clearing a wave gives a bonus.
5. Every monster that touches the Core damages it (Core health 20; vindicators 2, ravagers 5). Sneak + right-click the Core during prep to start the next wave early.

World difficulty must not be Peaceful. Works in singleplayer and on servers (everyone near the Core shares the game). Defense Core recipe (if you need another): 8 iron ingots around a diamond.

## Install
Drop `dist/towerdefense-1.0.0.jar` into the `mods` folder of a Minecraft 1.20.1 Forge profile.

## Build from source
Needs JDK 17.

    ./gradlew build        # jar appears in build/libs/
    ./gradlew runClient    # dev client
    ./gradlew runGameTestServer   # headless smoke test: spawns a game, checks towers clear wave 1

## Rebalancing
- Tower stats: `TowerStats.java` (range, fire rate, damage, splash, slow).
- Waves, enemy types, Core health, timings: top of `CoreBlockEntity.java`.
- Tower costs: `src/main/resources/data/towerdefense/recipes/`.
- Placeholder textures are generated by `tools/generate_textures.py` (replace the PNGs with real art any time).

## Publishing to CurseForge
Create a project of type *Mods*, game version 1.20.1, modloader Forge, and upload the jar from `dist/` (or `build/libs/`). Add a logo and screenshots on the project page.
